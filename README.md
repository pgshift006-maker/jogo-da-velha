# jogo-da-velha
Trabalho de programação: jogo da velha em Python, para dois jogadores, executado no terminal.

## Como executar

É preciso ter o [Python 3](https://www.python.org/downloads/) instalado. Na pasta do projeto, rode:

```bash
python main.py
```

## Como jogar

No menu, escolha uma das opções:

1. Jogar
2. Ver regras
3. Ver placar
4. Sair

Na partida, informe a linha e a coluna da casa desejada, com números de 1 a 3.
